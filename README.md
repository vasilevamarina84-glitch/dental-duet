Чат-бот для стоматологии «Дуэт»
Проект создан в рамках производственной практики. Это простой чат-бот, который отвечает на частые вопросы клиентов стоматологической клиники.
Ответы на частые вопросы:
  - Приветствие
  - Цены на услуги
  - Запись на приём
  - График работы
  - Адрес клиники
- Веб-интерфейс для общения (работает в браузере)
- Распознавание ключевых слов в сообщениях пользователя.

Технологии:
- Python 3.13 — язык программирования
- Flask— веб-фреймворк для создания интерфейса
- HTML/CSS/JavaScript — для оформления чата
- Git — контроль версий
- ngrok — для публикации бота в интернете.

Как запустить:
1. Установить Python и PyCharm.
2. Установить Flask: pip install flask:
3. Запустить файл `web_bot.py`.
4. Открыть в браузере: http://127.0.0.1:5000

Структура проекта:
- `web_bot.py` — основной файл 
- `main.py` — консольная версия бота
- `README.md` — описание проекта
